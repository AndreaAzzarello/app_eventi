# Brand kit di Eventi Vicini

| File | Uso |
|---|---|
| `logo-orizzontale-chiaro.svg` | Logo per sfondi chiari (testo scuro). |
| `logo-orizzontale-scuro.svg` | Logo per sfondi scuri (testo chiaro). |
| `social-preview.png` | Immagine 1280×640 per l'anteprima social del repository. |

Il pin è quello di `web/static/favicon.svg`. «Eventi» è in Fraunces 600, «Vicini» in Fraunces 600 corsivo, in terracotta. Il testo è convertito in tracciati: gli SVG non dipendono da font installati.
